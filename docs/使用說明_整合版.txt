Glassdoor 爬蟲工具 - 整合版使用說明
=====================================

【檔案說明】

✅ glassdoor_scraper_unified.py  - 整合版爬蟲（推薦使用）
✅ config.py                     - 配置文件（修改這個來添加公司）
✅ 啟動Chrome.bat                - 快速啟動 Chrome 的批次檔

舊版檔案（可以刪除）：
- glassdoor_scraper.py
- glassdoor_scraper_with_chrome.py
- quick_scrape.py
- config_example.py

【快速開始】

方法一：使用配置文件（推薦）
---------------------------
1. 編輯 config.py，修改 COMPANY_URLS 添加你要抓取的公司
2. 執行 啟動Chrome.bat
3. 在 Chrome 中登入 Glassdoor
4. 執行：python glassdoor_scraper_unified.py

方法二：直接執行
---------------------------
python glassdoor_scraper_unified.py

【如何添加新公司】

步驟 1: 找到公司的 Glassdoor URL
-------
在瀏覽器中搜尋：公司名稱 glassdoor reviews
例如：Google glassdoor reviews

步驟 2: 複製 URL
-------
URL 格式通常是：
https://www.glassdoor.com/Reviews/公司名稱-Reviews-E公司ID.htm

步驟 3: 編輯 config.py
-------
打開 config.py，在 COMPANY_URLS 中添加：

COMPANY_URLS = {
    # 現有的公司...
    'ASUS reviews': 'https://www.glassdoor.com/Reviews/ASUS-Reviews-E40093.htm',
    
    # 添加新公司（在這裡加）
    'Google': 'https://www.glassdoor.com/Reviews/Google-Reviews-E9079.htm',
    'Tesla': 'https://www.glassdoor.com/Reviews/Tesla-Reviews-E43129.htm',
}

注意：
- 每一行結尾要有逗號 ,
- 最後一行可以有或沒有逗號都可以
- 顯示名稱（例如 'Google'）會出現在 Excel 中

步驟 4: 儲存並執行
-------
儲存 config.py 後，執行程式即可

【配置選項說明】

在 config.py 中可以修改：

1. COMPANY_URLS
   - 要抓取的公司列表

2. SCRAPER_CONFIG
   - mode: 'manual' 或 'auto'
     * manual: 使用已登入的 Chrome（推薦）
     * auto: 自動啟動 Chrome（可能遇到驗證）
   
   - headless: True 或 False
     * True: 隱藏瀏覽器視窗
     * False: 顯示瀏覽器視窗

3. OUTPUT_CONFIG
   - filename: 輸出的 Excel 檔案名稱
   - sheet_name: Excel 工作表名稱

【常見問題】

Q: 如何一次抓取很多公司？
A: 在 config.py 的 COMPANY_URLS 中添加所有公司即可

Q: 抓取失敗怎麼辦？
A: 1. 確認已用 啟動Chrome.bat 啟動 Chrome
   2. 確認已在 Chrome 中登入 Glassdoor
   3. 確認 URL 正確

Q: 可以抓取不同國家/地區的評論嗎？
A: 可以！只要複製該地區的 URL 即可
   例如：
   'ASUS Taipei': 'URL1'
   'ASUS Singapore': 'URL2'

Q: 輸出的 Excel 在哪裡？
A: 預設在程式所在資料夾，檔名為 glassdoor_ratings.xlsx

【範例：抓取多家科技公司】

編輯 config.py：

COMPANY_URLS = {
    'Google': 'https://www.glassdoor.com/Reviews/Google-Reviews-E9079.htm',
    'Microsoft': 'https://www.glassdoor.com/Reviews/Microsoft-Reviews-E1651.htm',
    'Apple': 'https://www.glassdoor.com/Reviews/Apple-Reviews-E1138.htm',
    'Amazon': 'https://www.glassdoor.com/Reviews/Amazon-Reviews-E6036.htm',
    'Meta': 'https://www.glassdoor.com/Reviews/Meta-Reviews-E40772.htm',
    'Tesla': 'https://www.glassdoor.com/Reviews/Tesla-Reviews-E43129.htm',
    'Netflix': 'https://www.glassdoor.com/Reviews/Netflix-Reviews-E11891.htm',
}

然後執行程式，就會一次抓取所有公司的數據！

【技術支援】

如有問題請檢查：
1. Python 版本（建議 3.8+）
2. 套件是否安裝（pip install -r requirements.txt）
3. Chrome 是否正確啟動
4. 是否已登入 Glassdoor
